# Projeto Social Dorcas — GitHub Pages

Esta é a versão estática da aplicação institucional da Associação Projeto Social Dorcas. 

## Publicar no GitHub Pages

1. Crie um repositório público no GitHub.
2. Copie o conteúdo desta pasta `docs` para a raiz do repositório. A raiz deverá conter `index.html` e a pasta `assets`.
3. Faça commit e push dos arquivos.
4. No repositório, abra **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Escolha a branch `main` e a pasta `/ (root)`.
7. Clique em **Save** e aguarde a publicação.

O endereço será semelhante a `https://seu-usuario.github.io/nome-do-repositorio/`.

## Conteúdo e limitações

A versão mantém os projetos, notícias, diretoria, transparência, Pix, validações, modal, responsividade e mapa do Google Maps. 
Como o GitHub Pages não executa servidor, os formulários exibem uma confirmação local e não armazenam nem enviam dados. 
Para recebimento real, conecte-os posteriormente a um serviço de formulários ou substitua a ação por e-mail/WhatsApp.
